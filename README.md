# AuctionBay

Full-stack auction web application built with NestJS (backend) and React (frontend).

Users can create auction listings, place bids, and track auction progress in real time.  
When the auction ends, the highest bidder wins the item.

---

## 🚀 Features

- JWT authentication (signup / login)
- Create auction listings
- Edit / delete your own auctions
- Upload auction images
- Browse active auctions
- Place bids on auctions
- View bidding history
- Automatic auction finalization when end date is reached
- Auction status tracking (active / ended)

---
